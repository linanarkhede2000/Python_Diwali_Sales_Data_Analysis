# Python_Diwali_Sales_Data_Analysis
Project Overview:
This project is about analyzing sales data during the Diwali festival. I used Python to find out who buys the most, what products sell well, and which age groups and cities buy more. The goal is to help businesses understand customer behavior and improve their sales.
conclusion:
Married women age group 26-35 yrs from UP, Maharastra and Karnataka working in IT, Healthcare and Aviation are more likely to buy products from Food, Clothing and Electronics category
